Privacy Policy

Last updated: [today's date]

Physique Tracker is a personal, single-user application built for individual use and is not distributed publicly or made available to other users. It is not a commercial product.

Data Collected

The app accesses health and fitness data via the WHOOP API (recovery, sleep, strain, workout data), Apple HealthKit (body composition data), and user-entered nutrition and workout logs, solely for the purpose of personal tracking and analysis by the app's sole user and developer.

Data Storage

All data is stored locally on the user's own device. No data is transmitted to or stored on any third-party server, except as required to communicate with the WHOOP API (to retrieve authorized data) and the Anthropic Claude API (to analyze food photos and generate periodic progress summaries, at the user's initiation).

Data Sharing

No data collected by this app is sold, shared, or disclosed to any third party. The app is used exclusively by its single developer/user for personal health tracking.

Data Deletion

All data can be deleted at any time by deleting the app from the device, or by revoking WHOOP API access via the WHOOP mobile app's connected apps settings.
